# صيدلتي — Saydalati Pharmacy

نسخة مستقلة جاهزة لـ Node.js وHostinger، مبنية على Next.js ومتصلة بـ Supabase.

## التشغيل

يتطلب Node.js 22.13 أو أحدث ضمن إصدار 22، أو Node.js 24.

```bash
npm ci
npm run build
npm start
```

للتطوير: `npm run dev`.

## Hostinger

اختر إضافة موقع **Node.js Web App**، ثم اربط مستودع GitHub الجديد.

| الإعداد | القيمة |
|---|---|
| Framework | Next.js |
| Node.js | 22 أو 24 |
| Root directory | جذر المستودع |
| Install | npm ci |
| Build command | npm run build |
| Start command | npm start |
| Entry file عند طلبه | server.cjs |

الخادم يستمع إلى `0.0.0.0` ويستخدم منفذ `PORT` الذي توفره الاستضافة. لا تستخدم وضع Static أو رفع الملفات إلى public_html مباشرة، لأن تسجيل الدخول وبقية مسارات API تحتاج خادم Node.js.

أضف متغيرات البيئة في لوحة الاستضافة:

- `SUPABASE_URL=https://ihkrmzofpkrlwdlvorzi.supabase.co`
- `SUPABASE_PUBLISHABLE_KEY`: المفتاح العام من مشروع Supabase.
- `APP_ORIGIN`: رابط الموقع النهائي على HTTPS، مثل `https://pharmacy.example.com`.

لا ترفع ملفات البيئة الحقيقية أو كلمات المرور إلى GitHub. يحتاج التطبيق المفتاح العام فقط؛ إنشاء حسابات الموظفين يتم عبر Edge Function المحمية `pharmacy-accounts` الموجودة داخل Supabase.

## قاعدة البيانات والحسابات

قاعدة الصيدلية مثبتة بالفعل في المشروع أعلاه. لا تعِد تشغيل `database/pharmacy-schema.sql` على نفس المشروع. الملف مرجع لإعداد مشروع جديد فقط.

لم يُنشأ أول حساب سوبر أدمن بعد. يلزم إنشاء حساب Auth واعتماده كـ superadmin قبل بدء الاستخدام الحقيقي. لحينها تتوفر المساحة التجريبية المعلّمة بوضوح داخل الواجهة.

## المميزات

- واجهات السوبر أدمن وصاحب الصيدلية وموظف المبيعات.
- مواد ومخزون بتحويلات كارتون وعلبة وشريط ومفرد.
- مشتريات وتشغيلات وبونص وكلف شراء وصلاحية.
- نقطة بيع مع FEFO ومنع نفاد الرصيد وبيع المنتهي.
- شركات مجهزة ومستحقات وتسديدات ووصولات ومرفقات خاصة.
- تقارير مبيعات ومخزون ومجمل ربح وطباعة وتصدير CSV.
- بيانات كل صيدلية معزولة عبر RLS، وكلفة الشراء محجوبة عن المبيعات.

## الفحص

`npm run lint` يفحص TypeScript و`npm test` يفحص تحويل الوحدات وحركة المخزون والمدفوعات.

فحص PostgreSQL المتقدم في `tests/database.test.mjs` يحتاج تثبيت PGlite الاختباري. `database/live-verification.sql` ينفذ دورة اختبار داخل معاملة يتم التراجع عنها ولا يترك بيانات.

الإشعارات الخارجية، المرتجعات المحاسبية، المصروفات، والتحويل بين الفروع غير مفعلة في هذه النسخة. حساب السوبر أدمن واختبار دخوله الفعلي ما زالا مطلوبين.
